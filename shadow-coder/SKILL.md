# Shadow-Coder (Local LLM Agent)

Shadow-Coder uses your local **Ollama** models to handle heavy coding tasks. It is perfect for privacy, zero-cost development, and iterating on local codebases.

## Usage

You can trigger Shadow-Coder for any coding task where you want to avoid cloud costs or keep data local.

### Preferred Models
- **Default:** `qwen2.5:7b` (fast and capable)
- **High Power:** `deepseek-coder-v2` (requires more RAM)
- **Extreme:** `codestral` (best for complex logic)

## How to use the Shadow-Coder Script

The skill comes with a `coder.py` script that handles the context-gathering and interaction with Ollama.

```bash
# General command
python3 skills/shadow-coder/coder.py --task "Add a logout endpoint to auth.py" --files "src/auth.py,src/app.py"

# Custom model
python3 skills/shadow-coder/coder.py --model "deepseek-coder-v2" --task "Refactor the database module"
```

## Workflow for the Assistant
1. **Identify the files** that need to be modified.
2. **Read the content** of those files.
3. **Execute the Shadow-Coder script** with the task and file paths.
4. **Review and apply** the suggestions generated by the local model.

## Safety & Ethics
Shadow-Coder runs locally. It does not send your code to external servers. However, always review the code generated by the local model before executing it, as it may lack the safety filters of larger cloud models.
